# Aim:

To design and develop an AI-powered chatbot that can answer customer inquiries, provide product and order support, and improve the overall customer experience in a retail environment using effective AI prompting techniques.

# Algorithm:
1.Define the chatbot's objectives and customer support tasks.

2.Collect common retail customer queries (product availability, order status, returns, payments, etc.).

3.Design prompts using different AI prompting techniques.

4.Test the chatbot with various customer questions.

5.Evaluate the chatbot's responses for accuracy, relevance, and user satisfaction.

6.Analyze the results and identify areas for improvement.

7.Document the experiment and prepare the final report.

# Prompts Using Different AI Prompting Techniques:
# 1. Zero-Shot Prompting
# Prompt:
```
You are an AI customer support chatbot for an online retail store. Answer the customer's question politely and accurately.

# Customer:
"Do you have wireless headphones under ₹3000?"
```
# Output:
```
Yes! We have several wireless headphones priced under ₹3000. Some popular options include Boat Rockerz, Noise Buds, and Realme Buds Wireless. Would you like recommendations based on battery life or sound quality?
```
# 2. One-Shot Prompting
# Prompt:
```
# Customer:
"How can I return a damaged product?"

# Assistant:
"You can return a damaged product within 7 days of delivery. Go to 'My Orders', select the item, click 'Return', and choose 'Damaged Product' as the reason."

# Customer:
"When will my order arrive?"
```
# Output:
```
You can check your delivery date in the 'My Orders' section. Enter your order number to view the estimated delivery time and live tracking information.
```
# 3. Few-Shot Prompting
# Prompt:
```
Customer:
"What are your store timings?"

Assistant:
"Our online store is available 24/7."

Example 2:
Customer:
"Can I cancel my order?"

Assistant:
"Yes, you can cancel your order before it is shipped from the 'My Orders' page."

Customer:
"What payment methods do you accept?"
```
# Output:
```
We accept UPI, Credit Cards, Debit Cards, Net Banking, Wallets, and Cash on Delivery (where available).
```
# 4. Chain-of-Thought Prompting
# Prompt:
```
Think step-by-step before answering.

Customer:
"My payment was successful, but my order is not showing."

Explain the possible reasons and provide the best solution.
```
# Output:
```
Possible reasons:
1. Payment confirmation may still be processing.
2. The order may take a few minutes to appear.
3. A temporary server issue could have occurred.

Solution:
Wait for 10–15 minutes and refresh the 'My Orders' page. If the order is still missing, contact customer support with your payment reference number.
```
# 5. Role Prompting
# Prompt:
```
You are a senior customer service executive for a retail company.

Respond professionally.

Customer:
"I received the wrong product."
```
# Output:
```
We apologize for the inconvenience. Please initiate a replacement request through the 'My Orders' section within 7 days. Once the incorrect item is collected, the correct product will be shipped to you at no additional cost.
```
# 6. Contextual Prompting
# Prompt:
```
Context:
The customer ordered a smartphone two days ago.

Customer:
"Can I change my delivery address?"
```
# Output:
```
If your order has not been shipped, you can update the delivery address from the 'My Orders' section. If the order has already been shipped, please contact customer support to check
whether an address modification is possible.
```
# Result:

The AI-powered retail chatbot successfully handled common customer queries related to products, orders, returns, payments, and delivery. Different prompting techniques (Zero-shot, One-shot, Few-shot, Chain-of-Thought, Role, and Contextual prompting) improved the quality, accuracy, and relevance of responses, resulting in better customer support and an enhanced shopping experience.
